 
+---code

|   |   dataset.py -> Der Code bereitet die Bilddaten für das Deep-Learning-Modell vor, indem er Trainingsbilder mit ihren Klassenlabels sowie unlabeled Bilder für die spätere Klassifikation einliest und als PyTorch-Datensätze bereitstellt.
|   |   example_peak_detection.ipynb -> beispiel wie die Peakdetection funktioniert 
|   |   peaks.py -> Die Funktionen erkennen charakteristische Peaks im Sensorsignal, bestimmen daraus einen Schwellenwert und identifizieren anhand der Peaks die ersten und letzten Radüberfahrten sowie deren Zeitpunkte.
|   |   utils.py -> Die Funktion main() ruft die Sensordaten für einen bestimmten Tag ab, erkennt daraus die Messspitzen und berechnet anhand des Sensorabstands die Geschwindigkeit der vorbeifahrenden Züge.
|   |   
|   +---DataFrame -> ordner mit den verschiedene Dataframes für jeden tag und sensor mit den infos von alle züge die gefahren sind

|   |       
|   +---FTP
|   |   |   data_decoder.py -> Die Funktion decoder() liest die heruntergeladenen Rohdaten ein, dekodiert die 7-Bit-ASCII-/Hex-Daten in Messwerte, reduziert bei Bedarf die Abtastfrequenz von 4000 auf 1000 Hz und speichert die resultierenden Zeit- und Distanzwerte als CSV-Dateien.
|   |   |   data_download.py -> Die Funktion downloader() verbindet sich anhand des file_pattern mit dem entsprechenden FTP-Server, sucht dort nach den passenden ADTC-Dateien und lädt diese in den lokalen Ordner RAW_DATA herunter.
|   |   |   log.py -> Der Code erkennt anhand von file_pattern das entsprechende Projekt und gibt die zugehörigen FTP-Zugangsdaten, den Port und den Remote-Ordner zurück, wobei get_project_video() zusätzlich das Datum extrahiert, um den Pfad zum entsprechenden Videoordner zu erstellen.
|   |   |   video_download.py -> Der Code verbindet sich mit dem projektspezifischen FTP-Server, sucht dort nach .mp4-Videodateien und lädt diese für den angegebenen Tag in den entsprechenden lokalen VIDEO-Ordner herunter.
|   |   |   
|   +---GeoVis
|   |   |   DTC.env -> login und pw für den API zugriff (GeoVIS)
|   |   |   Geschwindigkeit.py -> Der Code berechnet anhand der erkannten Peak-Zeitpunkte die Geschwindigkeit jeder Achse zwischen aufeinanderfolgenden Sensorpaaren, interpoliert fehlende Geschwindigkeitswerte und speichert zusätzlich die Achsanzahl sowie die mittlere Zuggeschwindigkeit in dfs_raw.
|   |   |   
|   |   +---API
|   |   |   |   ADTC_Analyze_FHNW.py -> Der Code stellt die Schnittstelle zur GEOvis4.0-REST-API bereit, um sich anzumelden sowie Projekte, Sensoren und deren Messdaten abzurufen und verschiedene Sensor- und Projektinformationen zu verwalten.
|   |   |   |   Datenbezug_API.py -> Der Code ruft die Messdaten der ausgewählten Distanzsensoren über die API für den definierten Zeitraum ab, bereitet sie als Pandas-DataFrames auf und gruppiert die Messungen anhand von Zeitlücken von mehr als einer Minute zu einzelnen Datenabschnitten.
|   |   |           
|   |   +---Preprocessing
|   |   |   |   Peak_Detektion.py -> Der Code erkennt in den Sensordaten anhand definierter Schwellenwerte signifikante negative Signalspitzen (Peaks) und speichert die entsprechenden Messpunkte für jeden Zeitstempel und Sensor im Feld „Peaks“.
